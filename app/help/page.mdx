# Help

Welcome to the PuMi help center. Use the navigation above for a full **[getting started](/onboarding)** walkthrough, **[FAQ](/help/faq)**, and **[how-tos](/help/how-tos)**.

## What is PuMi?

PuMi is a **structure-before-code** canvas: you map **screens** (pages), **blocks** inside each screen, and **navigation** between them. Each page can include a **low-fidelity wireframe** so exports preserve layout intent—not just a bullet list.

When you are ready to hand off, **Export** turns the map into **Markdown**, **`.cursorrules`**, **`CLAUDE.md`**, or **JSON** for tools like Cursor, Claude, or other agents.

## Two modes on the canvas

1. **Site map** — The first tab in the top bar. Pages appear as nodes; **edges** show how users move between screens (e.g. navigation links).
2. **A named page tab** — Opens that screen’s canvas. Here you place **blocks** (major UI regions) and optional **wireframe** elements inside the page’s main block.

Switch tabs anytime; your work saves as you go (watch **save status** next to the project name).

## Plans at a glance

- **Free** — One saved project; all **export** formats (Markdown, **`.cursorrules`**, **`CLAUDE.md`**, JSON).
- **Premium** — More projects; **AI blueprints** (page templates), canvas **themes**, and **team** features where enabled.

Manage billing from **[Settings → Billing](/settings/billing)**.
