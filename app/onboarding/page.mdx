# Getting started

Use this checklist the first time you open PuMi. Experienced users can skim and jump to **[Help](/help)** or **[How-tos](/help/how-tos)** for details.

## 1. Sign in

From the **[home page](/)**, choose **Sign in** (or **Dashboard** / **New canvas** if you already have a session). You need an account so projects and canvas data can be saved to **your workspace** (backed by Supabase).

## 2. Open or create a project

- **[Dashboard](/dashboard)** — See all projects; **New project** creates one and opens the canvas.
- **New canvas** on the home page — Same flow when you are signed in.

The **free plan** includes **one** project; upgrade under **[Billing](/settings/billing)** for more.

## 3. Learn the canvas tabs

In the top bar, **page tabs** control what you are editing:

- **Site map** — Arrange **pages** as nodes and draw **edges** between them to show navigation or flow. Use **Add** beside the tabs to create another page. Open a page’s design from a node (e.g. **Open wireframe**) or by selecting that page’s tab.
- **A page name** — The **block canvas** for that screen: **blocks** are major regions; connect them to show relationships. You can add **wireframe** elements inside the page for layout detail.

**Save status** appears near the project name. On a **page** tab (not **Site map**), **Undo** / **Redo** step through block and wireframe edits. On **Site map**, use **Clear page links** to reset edges between pages; wireframe-specific **Clear** actions appear on page tabs.

## 4. Export your work

Click **Export** in the toolbar. Choose a format:

- **Markdown** — Human-readable spec and generic tooling.
- **`.cursorrules`** — Context tuned for Cursor.
- **`CLAUDE.md`** — Same structure in a Claude-friendly intro (save as `CLAUDE.md` in your repo).
- **JSON** — Structured data for scripts and other tools.

Use **Copy** or **Download** in the export panel to move the output into your repo or chat.

- **[FAQ](/help/faq)** — Accounts, storage, offline, exports.
